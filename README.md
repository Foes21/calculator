#Calculator

A Python 3 calculator used from the Terminal, built step by step in SCCM4910.
## What it will do
Add, subtract, multiply and divide two numbers; display the result.
## How to test it
Initialise environment with source /opt/python-venv/sccm-4910/bin/activate
Perform tests via execution of ./check.sh
Should return 5 successful passes
Exit status 0 means all passes successful, 1 indicates failure
## How to run it
Requirements: python3
Run: ./run.sh
Enter the first number, operator (+ - * /), then second number.
The program prints Result: followed by the answer.
Test case: '6', '*', '7' should output '42.0'
To terminate: Ctrl + C
